# 디자인 가이드 — INTERRA

**키워드**: 세련됨 · 고급스러움 · 절제 · 따뜻한 빛

## 컬러 (`public/css/style.css` 의 `:root`)
| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--ivory` | `#f6f1ea` | 기본 배경 |
| `--paper` | `#fbf8f3` | 카드·폼 배경 |
| `--sand` | `#ece3d6` | 이미지 바탕 |
| `--ink` | `#1b1815` | 본문·주 버튼 |
| `--gold` | `#a8824f` | 포인트(eyebrow, 강조, 호버) |
| `--gold-3` | `#e8d6b5` | 어두운 배경 위 텍스트 |
| `--noir` | `#15120f` | 다크 섹션(마퀴, 구매 방법, 푸터) |

## 타이포그래피
- 영문 디스플레이: **Cormorant Garamond** (로고, 숫자, 가격)
- 국문 제목: **Noto Serif KR** (가벼운 굵기, 자간 -0.03em)
- 본문: **Pretendard**
- Eyebrow: 12px, 자간 0.28em, 대문자, 금색 + 앞 가로선

## 모션 원칙 (`public/js/main.js`)
| 요소 | 효과 |
| --- | --- |
| 인트로 | 다크 커튼 위 로고 글자 상승 → 커튼 걷힘 (세션당 1회) |
| 히어로 | 펩타이드 체인 파티클 캔버스(마우스 반응), 제목 줄 단위 마스크 리빌, 제품 아치 클립 리빌, 회전 텍스트 링, 3D 마우스 틸트 |
| 스크롤 | Lenis 부드러운 스크롤, 단어 단위 제목 리빌, 이미지 클립 리빌, 패럴랙스, 숫자 카운터 |
| 시그니처 | PC: 고정 후 가로 스크롤 + 진행바 / 모바일: 스와이프 스냅 |
| 마퀴 | 무한 흐름, 스크롤 속도에 따라 가속 |
| 인터랙션 | 커스텀 커서, 마그네틱 버튼, 카드 3D 틸트, 버튼 골드 채움 |

- 이징: `cubic-bezier(0.22, 1, 0.36, 1)` / GSAP `power4.out`, `expo.out`
- `prefers-reduced-motion` 사용자에게는 모든 모션 비활성화
- 스크립트 로드 실패 시 4초 후 콘텐츠 강제 표시 (안전장치)

## 반응형
- 브레이크포인트: 520 / 640 / 900 / 1024 / 1200px
- 1024px 미만: 햄버거 메뉴, 하단 문의 바, 가로 스와이프 제품
- 좌우 여백 `clamp(20px, 4vw, 48px)`

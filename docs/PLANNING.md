# 기획서 — 제이앤코슈 홈페이지

## 목표
0. **인테라(INTERRA) 제품 카탈로그** — 상호는 제이앤코슈, 취급 브랜드는 인테라. 가격은 소비자가만 표시. `/catalog` 는 인쇄·PDF·링크 공유용
1. **검색 시 보여줄 공식 홈페이지** 확보 (네이버·구글 검색, 스마트플레이스 연결)
2. 제품·서비스 정보를 고급스럽게 전달
3. **모든 동선의 끝은 대표번호 문의** (010-4030-5956) — 온라인 결제 없음
4. 대표가 직접 상품(사진·설명·가격)을 관리

## 핵심 사용자
- 지인 추천·검색으로 들어온 40~60대 여성 고객 (모바일 비중 높음)
- 제품을 이미 알고 가격·구성을 확인하려는 재구매 고객

## 전환(문의) 동선
| 위치 | 행동 |
| --- | --- |
| 헤더 (PC) | 대표번호 버튼 → 전화 |
| 하단 고정 바 (모바일) | 전화 · 문자 · 상담 신청 |
| 우측 하단 버튼 (PC) | 전화 문의 |
| 제품 상세 | **전화로 구매 문의**(주 버튼), 문자 문의(제품명 자동 입력), 상담 신청 |
| 상담 신청 폼 | 성함·연락처·관심 제품·통화 가능 시간 → 관리자에서 확인, 웹훅 알림(선택) |

## 정보 구조
- 메인: 인트로 → 히어로 → 브랜드 스토리 → 시그니처 제품 → 약속 3가지 → 구매 방법 4단계 → 상담 신청
- 제품 목록(카테고리 필터) / 제품 상세
- 문의하기
- 관리자: 상품 · 문의 · 사이트 정보

## 콘텐츠 원칙
- 의약품 오인 표현, 인증 없는 기능성 표현 금지
- 가격 미정 상품은 ‘가격 문의’로 노출
- 결제 불가 사실을 상세·푸터에 명확히 안내

## 향후 과제 (제안)
- 실제 제품 사진 촬영·교체
- 카카오톡 채널 개설 시 링크 추가 (관리자 > 사이트 정보)
- 사업자등록번호·주소 입력 (신뢰도 및 검색 노출)
- 고객 후기 섹션, 이벤트/공지 게시판
